# Report Formatter

## Overview

A document automation application that turns PDF and Word files into reusable templates, with photo-assisted data entry, saved drafts and report exports.

## My contribution

Led product design, workflow requirements and implementation review using AI-assisted development.

- Shaped a visual template editor with draggable fields, background covers, accurate font sizing and undo/redo.
- Developed the reporting workflow around inline editing, photographs, calculations, annotations and PDF/Word exports.
- Defined whole-photo OCR behavior to extract temperature readings and match them to nearby fields.
- Specified revision-safe drafts, persistent storage and role-based company access.
